# 媒体库／艺术家目录重构记录

## 2026-09-01 修订结果

- 桌面端增加歌手搜索、真实后端排序和音乐风格筛选工具栏。
- 排序与筛选从页面标题操作区移入统一工具栏，状态和值均保持可见。
- 网格改为依据内容区实际宽度计算 3～6 列，不再把桌面侧栏计入可用宽度。
- 字母索引滚动使用与网格相同的列数、卡片高度和行间距，修复定位偏差。
- 桌面头像根据卡片宽度在 104～132px 自适应；移动端保持 64px 列表头像。
- 桌面与移动端统一使用低饱和人物占位头像。
- 卡片保留整卡点击、稳定 Hover、键盘焦点和单一“打开歌手”语义动作。
- 动效遵循系统“减少动态效果”设置。
